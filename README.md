# My Habitica Pets - Card Collection 🐺✨

A full-stack application that syncs your [Habitica](https://habitica.com) pets into a beautiful, interactive digital sticker album.

> **Status:** 🛠️ **Alpha - Functional Integration**
> Currently fetching live data from Habitica API.

## 🚀 The Project
This "sticker album" bridges the gap between game achievements and custom artwork:
- **Live Sync:** Automatically fetches your pet collection from the Habitica API.
- **Custom Cards:** Support for manual entries via JSON for special or custom-made pets.
- **Interactive UI:** A 16-bit RPG-inspired interface with dynamic 3D parallax effects.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Flexbox/Grid), and **TypeScript**.
- **Backend:** **Java 17** with **Spring Boot 3** & Maven.
- **Integration:** REST API (Habitica API v3) with secure environment variables.
