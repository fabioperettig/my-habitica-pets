# My Habitica Pets - Card Collection 🐺✨

A full-stack project to collect and display pets and items from [Habitica](https://habitica.com), mixed with custom artwork.

> **Status:** 🚧 **Pre-Alpha / In Development** 🚧
> This project is currently in early stages of development.

## 🚀 The Project
The goal is to create a digital "sticker album" where:
- Data is fetched from the Habitica API via a **Java Backend**.
- Custom cards can be added manually.
- The **Frontend** displays a beautiful, interactive collection.

## 🛠️ Tech Stack (Planned)
- **Frontend:** HTML5, CSS3, and **TypeScript** (Vite/Vanilla).
- **Backend:** **Java** with Spring Boot / Maven.
- **Database:** JSON-based storage (for now) / XML.

## 📂 Current Structure
- `/frontend`: TypeScript setup with JSON mock data (Functional).
- `/backend`: To be initialized (Java/IntelliJ).
